# Mandatory mesh-editing operator inventory

**Runtime checked:** Blender 5.2.0 LTS  
**Purpose:** compact completeness card for every operator named by the master curriculum. Detailed
cards remain authoritative where linked; this inventory prevents a combined card from silently
omitting a required behavior field.

| Operator | Purpose / preconditions / selection | Important parameters | Topology effects and common failures | Good use / bad use | API and typed support | Evidence |
| --- | --- | --- | --- | --- | --- | --- |
| Selection | Target verts/edges/faces in correct mode; selection mode changes interpretation | domain, extend, linked, loops/rings | No topology change; stale/wrong-domain selection mutates unintended geometry | Good: smallest semantic region; bad: broad select-all for local repair | `bmesh` flags/flush; typed ID selection | BMesh selection-flush lab, transaction labs |
| Extrude | Duplicate selected region and connect boundary; requires coherent selection | offset/vector, individual vs region | Adds verts/edges/faces; zero offset creates overlapping geometry | Good: primary form extension; bad: hidden zero-distance shells | `bmesh.ops.extrude_face_region`; typed `extrude_selection` | Bottle/Mug/Speaker sessions, ID tests |
| Inset | Create an interior face border from selected faces | thickness, depth, individual, boundary | Adds perimeter/support topology; excessive thickness overlaps or collapses | Good: panels/support borders; bad: using inset as arbitrary bevel | `bmesh.ops.inset_region`; typed `inset_selection` | Speaker/SoapDish sessions, ID tests |
| Bevel | Chamfer selected vertices/edges | offset, segments, profile, clamp, affect | Adds transition faces; excessive width collapses spacing and can distort corners | Good: controlled edge highlights; bad: masking poor base proportions | `bmesh.ops.bevel`; typed `bevel_selection` | `bevel.md`, modifier and transfer labs |
| Loop Cut | Insert an edge ring through compatible quad flow | edge/ring target, cuts, factor/even spacing | Splits a traversable quad ring; poles/triangles stop routing | Good: purposeful deformation/support density; bad: generic subdivision presented as a loop cut | typed `loop_cut_selection` now validates two opposite selected edges per traversed quad before BMesh subdivision | official video + rounded-housing transfer; false ring contract retained/fixed |
| Subdivide | Split selected edges/faces into denser topology | cuts, smooth, fractal | Adds samples; density alone does not improve flow and can preserve defects | Good: pre-deform sampling; bad: indiscriminate density | `bmesh.ops.subdivide_edges`; typed `subdivide_selection` | topology/SubD and deform labs |
| Knife | Draw arbitrary cuts through visible or occluded faces; interactive context often required | cut path, occlusion/cut-through, angle/midpoint constraints | Creates local edges/verts; near-coincident cuts create slivers | Good: deliberate local rerouting; bad: scripted freehand without reproducible coordinates | `bpy.ops.mesh.knife_tool` remains modal; typed deterministic plane-cut equivalent is `bisect_selection` | official video + current manual + rounded-housing Bisect transfer; freehand typed path remains gap |
| Bisect | Cut geometry by a defined plane | plane point/normal, clear inner/outer, fill | Splits crossing geometry; wrong normal/clear side deletes intended form | Good: deterministic planar cut; bad: ambiguous view-derived plane | `bmesh.ops.bisect_plane`; typed `bisect_selection` | `bisect.md`, expanded typed-op lab |
| Bridge Edge Loops | Connect compatible boundary loops | loop selection, twist, cuts, interpolation | Adds strip faces; mixed non-boundary edges can no-op or bridge wrong loops | Good: connect matched openings; bad: arbitrary edge bags | `bmesh.ops.bridge_loops`; typed `bridge_selection` | `bridge_fill_gridfill.md`, failure run |
| Spin | Revolve selected geometry around axis/center | angle, steps, axis, center, duplicate | Repeated rotational topology; wrong center/axis self-intersects | Good: lathed/revolved forms; bad: using many manual rotations | `bmesh.ops.spin`; typed `spin_selection` | expanded typed-op lab |
| Merge | Collapse selected vertices to a chosen target/center | merge mode or target ID | Removes verts/edges and may collapse faces; wrong target damages silhouette | Good: intentional convergence/poles; bad: cleanup by blind collapse | `bmesh.ops.pointmerge`; typed `merge_selection` | expanded typed-op lab |
| Merge by Distance | Weld vertices inside a threshold | distance, selected/all scope | Removes duplicates; excessive radius destroys nearby intended structure | Good: known duplicate cleanup; bad: treating it as universal repair | `bmesh.ops.remove_doubles`; no dedicated typed command yet | BMesh API lab |
| Dissolve | Remove selected elements while preserving surrounding surface where possible | vert/edge/face domain, angle delimiters | Reduces topology; broad limited dissolve can erase design edges | Good: density cleanup; bad: across curvature/features | `bmesh.ops.dissolve_*`; typed `dissolve_selection` | `dissolve_and_delete.md`, BMesh failure |
| Delete | Remove selected elements and dependent topology by context | vert/edge/face/context mode | Opens holes or removes connected elements; domain choice matters | Good: intentional removal/opening; bad: when surface continuity must remain | `bmesh.ops.delete`; typed `delete_selection` | `dissolve_and_delete.md` |
| Fill | Close a boundary with faces, often triangles | selected boundary, beauty option | Adds cap faces; arbitrary boundaries can produce poor fan/slivers | Good: simple planar holes; bad: curved production patch without flow plan | `bmesh.ops.triangle_fill`; typed `fill_selection` | bridge/fill card, typed-op lab |
| Grid Fill | Fill suitable paired-loop holes with a quad grid | span, offset, ordered boundary | Adds grid; overlap/incompatible loop count causes failure | Good: regular openings; bad: irregular or self-overlapping boundaries | `bmesh.ops.grid_fill` / `bpy.ops.mesh.fill_grid`; no dedicated typed command | preserved grid-fill failure |
| Edge Slide | Move selected edges constrained along adjacent topology | factor, even, clamp, flipped | Coordinates change without element-count change; can compress faces | Good: support-loop spacing; bad: freeform translation substitute | modal `bpy.ops.transform.edge_slide`; typed move is not equivalent | slide lab |
| Vertex Slide | Move vertices constrained along connected edges | factor, clamp, even | Coordinates change; junction ambiguity can choose unintended path | Good: local spacing; bad: arbitrary surface relocation | modal `bpy.ops.transform.vert_slide`; typed move is not equivalent | slide lab |
| Rip | Duplicate/split selected connectivity and move one side | fill, extend, mouse side | Opens a seam; context/side ambiguity is high and headless calls can fail | Good: intentional seam opening; bad: unattended modal execution | modal `bpy.ops.mesh.rip`; no typed command | preserved headless context failure |
| Split | Disconnect selected geometry in the same object | selected domain | Duplicates boundary verts while retaining object membership; can create loose shells | Good: local disconnected shell; bad: when object-level organization is required | `bmesh.ops.split`; typed `split_selection` | split/separate card, typed-op lab |
| Separate | Move selected geometry to a new object | selected/material/loose-parts mode | Cross-object identity discontinuity; new object/data created | Good: distinct component/material/edit lifecycle; bad: hiding continuity problems | deterministic BMesh copy/remove; typed `separate_selection` | expanded typed-op rollback lab |
| Symmetrize | Copy one side across an axis onto the other | source→destination axis, threshold | Creates/removes mirrored topology; pre-existing destination can overlap | Good: rebuild one clean half; bad: unclear source side | `bmesh.ops.symmetrize` uses `X/-X/...`; typed readable direction mapping | preserved direction/fixture failures |
| Normals | Recalculate or reverse face orientation | inside/outside, selected scope | Orientation changes, topology does not; closed-volume assumptions fail on open sheets | Good: repair known orientation; bad: hiding self-intersection | `bmesh.ops.recalc_face_normals`; mechanical helper, not artistic typed op | BMesh API lab |
| Shade Smooth | Interpolate vertex/corner normals across faces | by angle/custom split normals depending workflow | Appearance changes, not topology; broad smoothing can round intended hard edges | Good: curved surfaces with controlled boundaries; bad: technical-validity substitute | polygon smooth flags / shading operators; mechanical helper | shading card and production assets |
| Shade Flat | Use face normals per polygon | selected/object scope | Appearance changes, not topology; exposes faceting without repairing density | Good: planar/faceted intent and diagnosis; bad: concealing insufficient curvature sampling | polygon smooth flags / shading operators; mechanical helper | shading card and visual diagnosis |

## Completeness boundary

Every mandatory topic has purpose, preconditions/selection, parameters, topology effect, failure,
good/bad use, API/typed status, and evidence above. A listed card does not imply full parameter
coverage. Knife, Merge by Distance, Grid Fill, slides, Rip, normals, and shading remain deliberate
typed-surface exclusions or gaps where modal/context behavior or mechanical classification matters.
