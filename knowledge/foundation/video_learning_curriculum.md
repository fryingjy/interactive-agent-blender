# Video learning curriculum

This file converts the user-supplied discovery map into an evidence queue. It is not a bookmark
archive. A URL only becomes learned capability after the source has been inspected, its reasoning
has been written in project language, a different-shape Blender experiment has been run, a failure
case has been retained, and the resulting rule is linked from an operator/curriculum card.

## Promotion states

`DISCOVERED -> ACCESS_VERIFIED -> STUDIED -> EXPERIMENTALLY_TESTED -> RUNTIME_VALIDATED`

- **DISCOVERED:** title/search candidate only; no knowledge credit.
- **ACCESS_VERIFIED:** permitted video and captions/audio can actually be inspected.
- **STUDIED:** timestamped visual observations and version limits recorded.
- **EXPERIMENTALLY_TESTED:** a different-shape Blender test checks the mechanism and a failure.
- **RUNTIME_VALIDATED:** the learned rule succeeds in a non-fixture asset decision.

Search-result URLs in the supplied map remain discovery prompts. They are never cited as if a
specific lesson was watched. Gated, removed, bot-blocked, or transcript-only sources receive no
visual-study credit.

## Breadth map from the supplied links

The supplied list covers official channels, interface/transforms, mesh operations, topology, SubD,
modifier stacks, hard surface, stylized/game assets, retopology, sculpting, curves, reference work,
product/environment modeling, UV/materials, Geometry Nodes, lighting/render/camera, and
rigging/animation/simulation. Those categories are represented in the queue above. Individual
candidate links are promoted only when their content fills a named evidence gap; collecting more
URLs by itself does not advance coverage.
