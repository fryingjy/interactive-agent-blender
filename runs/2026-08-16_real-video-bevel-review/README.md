# Real official-video episode review: Bevel limiting

This run independently revisits the 165–205 second limit-method episode from
**Bevel Tool — Blender 2.80 Fundamentals** (Blender / Dillon Gu), hosted by
Wikimedia Commons under CC BY 3.0. The temporary WebM was decoded locally for
frame and speech evidence and is not retained.

The retained frames demonstrate a narrow distinction relevant to the active
hard-surface policy: `NONE` is indiscriminate, `ANGLE` is a geometric threshold,
and an explicit Weight or Vertex Group is a deliberate selection mechanism. This
does **not** make Weight automatically appropriate: the reference, component
function, desired highlight, and shading path still determine which edges should
carry a radius.

The episode is independently reviewed by `episode_review.json`. The video lesson
is reconciled with the already reproducible Blender 5.2 semantic-edge policy lab
instead of producing a duplicate primitive-only experiment. No new modeling skill
is promoted from this episode alone.
