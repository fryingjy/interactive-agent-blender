# Independently reviewed reference-setup video episode

The public 3DTudor lesson **Blender References Not Working | How To Set Up References Tutorial**
was analyzed through an identity-bound Gemini whole-video pass and a native range-scoped 24–124 s
pass. Gemini inspected video, audio, captions, and UI text; no source video was downloaded or
archived.

Independent in-app-browser review retained five frames and sampled visible machine captions. The
24–124 s perspective-import failure and orthographic re-import correction passes every episode
alignment predicate. Later whole-video timestamps were not trusted: direct playback had already
entered external reference-board discussion around 142 s, contradicting the initial extraction's
later ranges.

The verified episode supports a narrow setup claim only. It does not prove that a photograph is
orthographic, that duplicated cards are true multi-view evidence, or that aligned cards improve
model fidelity without a Blender transfer.
