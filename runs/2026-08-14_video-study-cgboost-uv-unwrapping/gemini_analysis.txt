Here are the key instructional moments and transferable techniques from the tutorial:

---

### 1. Applying Non-Uniform Object Scale Before Unwrapping
* **Timestamp:** `01:42` – `02:10`
* **What is visible:** The `Transform` panel (N-menu) showing `Scale` values for objects in Object Mode; the operator menu `Apply -> Scale` (`Ctrl + A`).
* **Action & Purpose:** The instructor checks that all object scale transforms are uniformly `(1.0, 1.0, 1.0)`. Any object scaled in Object Mode is reset via `Ctrl + A -> Apply Scale` before unwrapping.
* **Transferable Takeaway:** If an object has unapplied non-uniform scale (e.g., scaled `(1.0, 2.0, 0.5)`), Blender's UV unwrapping algorithm calculates proportions based on the unscaled base geometry, resulting in stretched, distorted UV projections and textures on any 3D asset.

---

### 2. Enabling UV Sync Selection to Prevent Confusion
* **Timestamp:** `04:24` – `04:47`
* **What is visible:** The top-left header of the UV Editor; toggling the **UV Sync Selection** icon (two opposing arrows).
* **Action & Purpose:** By default, the UV Editor only displays faces currently selected in the 3D Viewport. Enabling UV Sync Selection keeps the entire UV map visible at all times while keeping vertex/edge/face selections strictly synchronized between 2D and 3D views.
* **Transferable Takeaway:** When inspecting complex meshes, keeping UV sync enabled prevents the feeling that parts of the UV map are missing, making it immediately obvious which 3D surface corresponds to which 2D UV island.

---

### 3. Isolating Geometry with Linked Selection and Hide (`L` & `H`)
* **Timestamp:** `05:39` – `06:01`
* **What is visible:** Hovering over the apple body in Edit Mode, pressing `L` to select linked geometry, pressing `H` to hide it, leaving only the stem visible to place seams on its top ring and side.
* **Action & Purpose:** The instructor isolates dense or obscured geometry (the stem) without leaving Edit Mode, places seams (`Right Click -> Mark Seam`), and reveals everything with `Alt + H`.
* **Transferable Takeaway:** On multi-part meshes or tight crevices (e.g., screws inside a socket, eyes inside head geometry), hiding large outer meshes with `L` then `H` gives an unobstructed view to select clean edge loops for seams.

---

### 4. Adjusting UV Island Margins
* **Timestamp:** `06:12` – `06:30`
* **What is visible:** After running `UV -> Unwrap`, the operator panel in the bottom-left corner appears with the `Margin` slider; increasing it increases padding between the four apple lobes and stem islands.
* **Action & Purpose:** Adjusting the margin slider adds breathing room between separate UV islands to prevent texture bleeding during texture painting, baking, or mipmapping.
* **Transferable Takeaway:** For any asset intended for texturing, setting a small margin (> 0.01–0.05) ensures adjacent colors on separate islands do not smear across borders into unintended areas of the 3D model.

---

### 5. Preserving Uniform Texel Density Across Islands
* **Timestamp:** `07:03` – `07:35`
* **What is visible:** The UV editor showing the apple lobes; demonstrating moving and rotating islands (`G`, `R`) vs. scaling them individually (`S`).
* **Action & Purpose:** The instructor cautions against scaling individual islands to fit empty spaces. If islands need resizing, all islands on the mesh should be selected and scaled together (`A` then `S`).
* **Transferable Takeaway:** Uniform island scale guarantees consistent texel density (pixels per unit of 3D surface area). Scaling one island larger gives that section higher texture resolution than the rest, leading to visible resolution mismatch and inconsistent detail across the asset.

---

### 6. Multi-Object Editing for Unified UV Space
* **Timestamp:** `08:48` – `09:12`
* **What is visible:** Selecting both the knife handle and knife blade objects in Object Mode and pressing `Tab` to enter unified multi-object Edit Mode; both objects' UVs display simultaneously in the UV Editor.
* **Action & Purpose:** Entering Edit Mode with multiple objects selected allows unwrapping and packing all related sub-components onto a single shared UV layout texture sheet.
* **Transferable Takeaway:** For modular props, vehicles, or weapons with separate movable objects (e.g., blade, handle, bolts), unwrapping them together ensures they share one material atlas and maintain matching scale without needing manual merging.

---

### 7. Selecting Seam Lines Using Shortest Path (`Ctrl + Click`)
* **Timestamp:** `10:04` – `10:24`
* **What is visible:** In Edge Select Mode on the knife blade, clicking one edge, then holding `Ctrl` and left-clicking an edge farther down the perimeter; Blender automatically highlights the shortest connected edge path along the boundary.
* **Action & Purpose:** Using Shortest Path selection allows fast, accurate marking of seam cuts along long hard-surface edges where loop selection (`Alt + Click`) stops due to non-quad topology or sharp corners.
* **Transferable Takeaway:** On hard-surface meshes and bevelled borders where edge loops terminate unexpectedly, `Ctrl + Click` cuts manual selection time down to 2–3 clicks for long perimeter seams.
