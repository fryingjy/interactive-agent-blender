# Blender Guru lightbulb tutorial reproduction

This is beginner apprenticeship evidence based on Blender Guru's two-part **Make a Lightbulb
Scene** lesson. It is not a held-out prop pass and it does not authorize advancement. The creator
page, both video identities, a creator-published bulb reference, and the creator's finished scene
were inspected before the final comparison. Full Gemini audiovisual extraction was attempted but
remains pending because the configured free-tier quota was exhausted; no claim here depends on
pretending that extraction succeeded.

## Modeled lesson artifact

The typed v3 bulb uses the tutorial's appropriate representations instead of unrelated primitive
stacking: 20-segment revolved profiles for the glass envelope and metal shell, 16-segment revolved
profiles for the contact and inner stem, Bezier curves for lead wires and screw thread, and a curve
for the tungsten coil. These are separate objects only where the real bulb has an assembly,
material, or curve-workflow boundary. The glass keeps a live Subdivision Surface modifier and the
thread remains a live 37-point, 4.5-turn Bezier helix; modifiers are not applied.

The production scene creates one linked master, sixteen linked copies, and one separately shaded
glowing copy on a striped reflective floor. `lightbulb_tutorial_scene_v4.blend` is the latest saved
file and `lightbulb_scene_v4.png` is its render. `independent_verification_v4.json` is generated by
opening that file in a clean Blender process and verifies structure, live modifiers/curves,
component presence, compositor glare, and base mesh health. It deliberately does not convert those
technical checks into a visual-fidelity pass.

## Retained failures and corrections

1. The first typed sequence used a stale render command. Geometry succeeded; only the diagnostic
   command failed. `typed_model_attempt_summary.json` retains the failure without duplicating full
   mesh dumps.
2. The first bulb profile was too short and squat relative to the creator reference. V2 elongated
   the envelope; v3 preserved that correction.
3. The first screw ridge was coarse and read as roughly three oversized rings. V3 replaced it with
   a finer 4.5-turn live Bezier helix.
4. The production compositor initially used Blender's removed pre-5.0 scene node-tree assumptions.
   The scene now uses `Scene.compositing_node_group`, a compositor node group, and live glare.
5. Scene v1 reduced unlit bulbs to black silhouettes. V2 added fill but exposed opaque-looking
   Eevee glass. V3/v4 use blended glass so internals remain visible.

## Visual review

The v4 bulb construction is recognizably closer to the supplied incandescent reference, but the
finished scene is only **7.2/10** against the creator result and therefore **does not pass** the
strict 8/10 gate. The render is too blue and transparent, overlapping envelopes produce ghosted
silhouettes, the glowing bulb is too orange and visually dominant, and the layout is more crowded
and frontal. The lesson is retained as a useful technical reproduction and an honest visual
failure. Beginner study continues; held-out prop modeling stays paused.
