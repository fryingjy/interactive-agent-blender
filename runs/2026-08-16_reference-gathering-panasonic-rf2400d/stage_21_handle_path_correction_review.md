# Stage 21 — Editable handle-path correction

The carry handle was revised in place through its existing six-point BEZIER
path, while retaining the authored flattened bevel profile.  The command
sequence changed no mesh topology and did not create a replacement handle.

## Result

The operation succeeded and the saved scene remains editable.  Lowering and
tightening the path improves the handle's gross height relative to the
official front photograph.

## Visual verdict

This is **not** an acceptance of the radio model.  The front diagnostic still
shows material mismatches that a global silhouette score cannot capture:

- The housing is a generic rounded box rather than the reference's more
  rectangular front surround and controlled side transitions.
- The handle is still visually tube-like and lacks the reference's broad,
  nearly flat top section and attachment geometry.
- The speaker grille, tuner layout, controls, and scale relationships are
  only placeholders, not a reference-faithful construction.

The value of this stage is the tested revise-after-observation path: a
continuous secondary form can now be corrected without adding another object
or collapsing its editable curve/profile construction.  It does not show
professional visual transfer and does not justify detail work on this asset.
