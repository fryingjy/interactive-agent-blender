# Field report

Open `index.html` directly in a browser. It is intentionally a dependency-free interactive report:
the project has no existing frontend build system, and a static document remains inspectable locally,
on GitHub, and in a future Pages deployment without introducing a package/runtime maintenance burden.

The report is a navigation layer, not the source of truth. Its claims must remain linked to current
code, retained run evidence, and the research roadmap. When those sources change materially, update
this report in the same change set.
