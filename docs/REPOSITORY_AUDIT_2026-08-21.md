# Repository audit — 2026-08-21

## Scope and decision rule

The audit compared current code, tracked files, recent commits, current-state documents, benchmark
state, knowledge status, source retention, exact duplicates, target-specific tools, and the latest
modeling runs. Deletion was limited to files that were clearly redundant, obsolete, unreferenced,
or direct violations of later user instructions. Negative evidence, generic typed operations,
reusable verifiers, source provenance, and controlled failures were retained.

## REMOVED

- The dependency-free HTML field report and its README. Direct user instruction had already ended
  HTML review boards; retaining a current-state HTML navigator contradicted that instruction.
- Eight unreferenced camera/Matteo object-specific builders, probes, exporters, and verifiers, plus
  the obsolete object-specific multiview-barrel generator. Their raw evidence had already been
  removed or rejected; no current code, test, or report invoked them.
- Exact duplicate evidence copies reported by `tools/audit_repository.py`: repeated comparison
  masks/overlays, a repeated Panasonic segmentation preview, duplicate retrieval benchmark v9, and
  an unreferenced directive-audit recheck. Later or authoritative copies were retained.
- Four ignored Blender autosaves left inside directories whose tracked model builds had been
  deleted. They were local temporary artifacts, not evidence.

## KEPT

- Transaction-owned rollback, state fingerprints, typed operations, persistent IDs, stage gates,
  rendering passes, reference-set audits, generic profile/grid construction, and independent
  verifiers.
- Failure reports and the 2026-08-19 circular-validation audit.
- The source registry and retention ledger. Seventy missing historical artifacts remain explicitly
  classified; classification does not turn them into reproducible evidence.
- Source-gathering tools that still reproduce retained reference packages, even when target-named.
- The donut/mug tutorial scene as a bounded training artifact, not a capability claim.

## FIXED

- The progressive benchmark no longer claims deleted KUPONG geometry is active.
- The current gap matrix no longer calls deleted MasterLock resume artifacts active or accepted
  current evidence.
- Reporting coverage no longer points to the deleted HTML field report.
- Candidate predictions now read measurements from independent observation records. A candidate
  cannot carry both a proposed representation and the value used to prove it.
- Candidate selection now requires a unique contradiction-free winner confirmed across multiple
  views; ties and unsupported evidence remain `AMBIGUOUS` or `INSUFFICIENT_EVIDENCE`.

## STILL SUSPECT

- Many historical documents name intentionally removed runs. They are acceptable only as labeled
  history and must not be promoted back into current claims.
- The source registry is not locally reproducible as a whole because retained third-party media and
  old run artifacts were intentionally removed.
- Most unit tests prove implementation behavior. They do not establish artistic judgment.
- The current consequence evaluators cover orthographic boundary linearity, independent numeric
  ranges, and boolean states. Visual curvature, occlusion, and cross-view landmark correspondence
  still require a real failure before adding another evaluator.
- The AA/LR6 case is intentionally simple and rotational; it does not close the difficult
  reference-to-form gap.
