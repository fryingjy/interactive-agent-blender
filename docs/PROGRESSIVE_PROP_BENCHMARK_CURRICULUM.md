# Progressive prop benchmark curriculum

This is the repository-operational interpretation of the user-supplied
`PROGRESSIVE_PROP_BENCHMARK_CURRICULUM_CODEX.md`. The supplied document is project guidance; it is
not independent evidence of capability and does not override later direct user instructions.
Machine-readable authority, gates, evidence requirements, and active state live in
`knowledge/foundation/progressive_prop_benchmark_curriculum.json` and are checked by
`tools/validate_progressive_prop_curriculum.py`.

## Promotion contract

Every prop must pass applicable reference interpretation, blockout, primary-form, secondary-form,
surface/topology, production, and human-review gates. Technical validity, manifold state,
silhouette IoU, or one acceptable render cannot authorize promotion by itself. Human rejection
overrides an automated pass.

The retained evidence contract includes the reference manifest/board, modeling brief, uncertainty
and strategy records, scoped decision log, stage gates, controlled visual passes, fresh-process
verification, human review/repair tickets, final editable `.blend`, and transferable lesson record.

## Active state

The KLF03 electric-kettle attempt is the current terminal failure record. Its final checkpoint is
technically valid and editable, but the user rejected its resemblance. Component-level silhouette
checks showed normalized overlap of 0.4001 for the spout, 0.5741 for the handle, and 0.5156 for the
base; whole-object normalization had obscured those errors. The model is therefore not promoted and
will not receive more target-specific cosmetic repair.

The ladder advances to Prop 5, Vintage Alarm Clock, only after the reusable component-level reference
comparison and recoverable component-rebuild workflow has been exercised on a focused reproduction.
Direct user instruction removes any pre-model approval-board requirement; it does not remove the
requirement for reference fidelity or the authority of a later human rejection.
