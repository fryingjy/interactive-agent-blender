# Reference: simple coffee mug (adaptive-decisions milestone)

Genuinely unseen for this milestone — no prep files existed for this object before this session.
Written proportions spec (no image download requested), deliberately simple but with a real
adaptive-modeling opportunity: the handle attachment is where a first attempt is likely to need
real correction (thickness, curve quality, attachment topology), not just formula-driven success.

- Body: cylinder, radius 1.2, height 2.8, base at z=0.
- Rim: top edge gets a small outward bevel for a finished lip (radius 1.2 -> ~1.25 at the very top
  edge, over the last ~0.1 of height).
- Wall: solid for this milestone (no hollow interior) — matches the earlier bottle/flashlight
  precedent; hollowing is optional future polish, not required for the adaptive-decision proof.
- Handle: a single C-shaped loop attached to the side wall, roughly spanning z=0.7 to z=2.1
  (a comfortable hand-width), standing proud of the body by about 0.9 units at its outermost
  point. Thickness/cross-section and exact curve are NOT pre-specified numerically — that's the
  point of this milestone: the agent has to look at the actual result after each step and decide
  whether it reads as a mug handle, not just execute a fixed plan.
- Symmetry: rotationally symmetric body (16-sided cylinder), handle is a one-off asymmetric
  addition on a single side, unlike the bottle/flashlight rings which were symmetric details.
