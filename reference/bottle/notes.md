# Reference: simple bottle (Proof 3)

Written proportions spec (no image download requested) for a small round bottle, used as the
target for milestone 2/3's reference-modeling proof.

- Overall height: ~10 units. Body diameter: ~3 units.
- Base: flat, slightly rounded edge (small bevel), diameter ~3 units, height ~0.
- Body: cylindrical, straight sides, from height 0 to ~7.
- Shoulder: body tapers inward from diameter ~3 to neck diameter ~1 over height ~7 to ~8.5,
  convex curve (not a hard cone) — profile bulges slightly outward before narrowing.
- Neck: cylindrical, diameter ~1, height ~8.5 to ~9.5.
- Lip: neck flares slightly outward at the very top (diameter ~1.2) over height ~9.5 to ~10,
  with a small bevel on the rim edge.
- Wall thickness: solid for this proof (no hollow interior needed) — a solidify/hollow pass is
  optional polish, not required for the topology proof.
- Symmetry: rotationally symmetric around the vertical (Z) axis — built from a profile curve
  extruded/scaled ring by ring, or a cylinder progressively edited (inset/extrude/scale per
  section), not a lathe/spin modifier, so each section is its own discrete verified action.
